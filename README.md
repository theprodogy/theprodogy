### About me

I'm **revsies**, a developer from Vienna. Most of what I build is Java for Minecraft: Paper and Folia plugins, server tooling and the configs behind my own networks. Lately I've also gotten really into making **Discord bots**.

- Running Minecraft Java servers, from FFA/KitPvP to SMP
- Building plugins for Paper, Folia and Leaf, targeting 1.21.11 and newer
- Making Discord bots and the small web apps around them
- Currently working on **[BetterEnderchests](https://github.com/theprodogy/BetterEnderchests)**
